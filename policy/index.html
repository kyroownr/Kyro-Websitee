Policy

Policy & data

This page covers the three things people ask about: what Kyro stores in your browser, what the account panel’s cookie switches actually change, and what a Kyro Discord membership unlocks.

Cookies and local storage

Kyro sets no advertising, analytics or third-party tracking cookies, and loads no analytics script. The site keeps a few values in your browser’s local storage so it works:

  • kyro.saved.v3 — the listings you bookmarked.
  • kyro.auth.v1 — your Discord display name, avatar and the session token from signing in. Cleared when you sign out or reset the preferences below.
  • kyro.os.v1 — whether you picked Windows or macOS.
  • kyro.oauth.state.v1 — a short-lived value that proves a sign-in redirect came from this browser. Removed as soon as it is used.

The Cookie Preferences panel in your account lists the categories Kyro recognises. Essential storage is always on because the site cannot sign you in without it. The Functional and Analytics switches are present for completeness: no optional category is in use today, so turning them off changes nothing on the site. “Reset All Preferences” clears the saved values above and the toggles return to their default state.

Kyro does keep five aggregate counters so the owner can see what needs attention: how many times a listing was opened, how many Discord sign-ins succeeded, how many download links were handed out, how many broken-link reports arrived, and how many community submissions were made. A count is never stored with a name, user id, session token or address, no cookie is set for it, and only the owner sees the totals. A broken-link report stores the listing id and the note you type, nothing else. Where these totals appear, they are anonymous.

What signing in with Discord shares

Signing in asks Discord for two scopes: identify and guilds. That returns your Discord user id, display name and avatar, plus the list of servers you are in — Kyro reads that list only to check whether the Kyro server is in it. Kyro does not read your messages, your email, your friends or any other server’s content.

The worker keeps a record of your Discord user id where it has to: to confirm membership, to count one download per member instead of one per click, and to attach a request, feedback post or staff application to the account that submitted it. Nothing about your browsing is logged or shared.

What membership unlocks

Every listing — description, preview images, file list, version, publisher and install guide — is readable with no account. Joining the Kyro Discord and verifying unlocks exactly three things: the download link for a gated file, the archive password when the publisher supplied one, and the #help channel for install support. A listing whose file is hosted by the original creator links out instead of serving a file from Kyro.

A download link is not a safety guarantee. Kyro publishes a scan status or review record only when one was actually recorded for that listing; where a panel says “Not recorded”, none was. Scan anything you download, and read Kyro’s DMCA & copyright policy for how takedowns are handled.

If a download link does not work, use Download not working? Report this link on the listing — no account needed. The report reaches the owner, and contributors can see the same rules they are held to on the contributor rules page.

Questions or removal requests

Open a ticket in the Kyro Discord. Rights holders asking for a link to be removed should say so in a copyright-removal ticket and include the details listed on the DMCA page.
