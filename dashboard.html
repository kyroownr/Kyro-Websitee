Server Setup

One-click configuration — full server preset, best-practice permissions, verification and tickets.

⌨️ Slash commands
Registers /setup, /mod, /role, /whois, /invite, /stats, /sync and /start-kyro in every server the bot is in. Discord only shows commands that have been registered — if /setup verification or the mod commands never appear, run this. Safe to re-run; commands update instantly.
⚡ One-Click Server Setup
Creates #welcome, #mod-log and #announcements, enables Welcome + full Logging + AutoMod (scam/invite/mention filters on every channel), turns on security defaults and sets up verification with every channel hidden until members verify. Safe to re-run — existing channels are reused.
🛡️ Auto Permissions
Rewrites role permissions to best practice across 20 presets: ownership and leadership, head/mod/security staff, support and helpdesk, media, events/DJ, creators, developers and testers, VIP/donors, level and gaming-squad roles, language/region, ping-only and cosmetic roles, age-gated access, alumni and punishment roles, and general members. Anything unmatched is optimised to a safe chat baseline. Bot/integration roles, @everyone and roles above the bot are protected. Requires Administrator — the dashboard asks for it up front.
🧹 Role cleanup
Deletes dead roles in bulk. @everyone, owner / admin / moderator / staff roles, bot and integration roles, roles above the bot, and every role the bot's automations rely on are always protected. Pick how many roles to keep — the busiest ones stay and the unused ones go.
👁️ Channel access repair
Fixes “You do not have permission to view the message history of #channel”. Re-adds the @everyone view + read-history overwrite and makes sure the bot can post, embed and manage its own messages. Other overwrites in the channel are left alone.
🎭 Role packs
Installs a ready-made role hierarchy for a server type — gaming, community, support, creator, music, art, developers, education, business, roleplay or 18+. Existing roles are reused, so it is safe to re-run.
🧩 Role preset picker
Give any single role a ready-made permission set without touching the rest of the server. Presets cover leadership, staff, support, media, events, creators, VIPs, level roles, ping roles, cosmetics and punishment roles.
✅ Verification
Posts a Verify button that grants the Verified role and hides every other channel until members press it — verification is mandatory. Members can't type in the verify channel until verified. The button works in Discord directly (handled by the Kyro worker).
🏷️ Set default role (everyone)
Gives the chosen role to every current member of the server — for example, put everyone in Verified. Bots are skipped and members who already have the role are left alone. This only affects people in the server right now; use Auto Role (Engagement tab) to give it to future joins too. Requires Manage Roles and the Kyro Bot role above the target role.
📺 Channel visibility (community layout)
Opens the community channels to everyone — alert, social-media, partners, requests, feedback, announcements, rules, download-links, questions, suggestions, showcase, general-chat, resources, flexx, incomming, help and staff-applications — and locks the Staff for mods+ hub (transcript-log, vault-asset-storage, updates-for-mods) to staff only. The verify channel and private ticket channels are left untouched. Bot review replies stay in private tickets. Requires Manage Channels.
🎫 Support / Modmail Tickets
Posts an Open Ticket button. Members get a private channel only they, the mod role and the owner can see — with a Close Ticket button. Duplicate tickets are detected automatically.

Security

Raid mode, anti-nuke, lockdown, keyword alerts, warning escalation, mass actions and mod activity.

🚨 Raid Mode & Auto-Raid Detection
Raid Mode locks sending in every text channel at once. Auto-Raid watches for join spikes — if more members than the threshold join within a minute, the server locks automatically and #mod-log gets an alert.
🛡️ Anti-Nuke
Watches the audit log for rogue admins deleting channels/roles, mass-banning members or creating webhooks. When someone crosses the threshold they lose all their roles instantly (and optionally get banned). The server owner and this bot are always trusted.
🔒 Global Lockdown
Manually lock or unlock message sending in every text channel — independent of Raid Mode state tracking.
🍯 Honeypot trap
A decoy channel no real member should ever post in. Anything written there is treated as bot or spam traffic: the message is deleted and the author is kicked, banned or timed out. Staff roles are never punished, so a moderator can test it safely. Detection runs on the background poller, so no gateway connection is needed.
No triggers yet.
The panel posted in the channel explains what a honeypot is and shows live server statistics — it updates itself after every catch.
🚩 Keyword Alerts
Scans recent messages in your AutoMod channels and reports anything matching these terms to #mod-log — self-harm phrases, scam bait, doxxing links.
⚖️ Warning Escalation
Automatic punishment when a member accumulates warnings — no mod has to remember to escalate.
💥 Mass Ban
Ban a list of user IDs in one go (raider dumps, bot waves). Every banned user still gets the DM + unban-request button.

Who is actually moderating — actions recorded from this dashboard per moderator.
