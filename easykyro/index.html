Get EasyKyro

Request anything, from any page

A small Chrome extension for the Kyro vault. Find an effect, a preset or a plugin you want while you are browsing, type one title, and EasyKyro writes the rest of the request for you — then files it on the Kyro requests board.

Download EasyKyro .zip Read the install steps

v1.3.0 · Chrome 127 or newer · Windows & macOS · no account needed to install

⚡ Using EasyKyro makes your request a priority request

Requests sent with the extension are stored as priority, not as a plain manual entry. They sit at the top of the Requests board with a ⚡ PRIORITY chip, and the Discord request card says ⚡ PRIORITY · sent with EasyKyro so staff can see where it came from. Same worker, same board, earlier in the queue.

Step-by-step installation

  1. Download the .zip

    Use the download button above. It saves easykyro-extension.zip to your Downloads folder — about 38 KB.

  2. Extract the archive

    Right-click the .zip → Extract All… on Windows, or double-click it on macOS. You get a folder called easykyro-extension. Chrome installs the folder, not the zip file, so keep it somewhere permanent (not your Downloads folder, which you may clean out).

  3. Open chrome://extensions

    Paste that into Chrome's address bar. Turn on Developer mode with the switch in the top-right corner.

  4. Drag the folder into the page

    Drop the extracted easykyro-extension folder anywhere on the chrome://extensions page. Or click Load unpacked and pick the folder. Either way Chrome adds EasyKyro to your list.

  5. Pin it, then connect Discord

    Click the puzzle-piece icon and pin EasyKyro. If you are already signed in on kyro.new.tg, the popup shows Connected as @you by itself; otherwise press Connect Discord and sign in on the Kyro tab that opens.

  6. Add a free Google AI key (recommended)

    Open EasyKyro's settings and paste a key from aistudio.google.com/api-keys. The key is checked on paste, saved only in your browser, and EasyKyro picks the cheapest Gemini model your key allows. No model picker, no key on Kyro's servers.

  7. Send your first request

    Browse to the page with the asset you want, press Alt+Shift+K (or right-click → Send this page to EasyKyro), type a title, then Review & send. It lands on the Kyro requests board and in the Discord requests channel.

What it does

One title is enough

Type the name of what you want. EasyKyro reads the page — title, meta description, first heading, your text selection and a short excerpt — and writes the description itself.

⚡ Priority on the board

Every submission is tagged as coming from EasyKyro, so it is stored as a priority request and listed first, with the chip on the site and on the Discord card.

Bring your own free key

The AI step runs on a Google Gemini key you own. It is verified on paste, saved in chrome.storage only, and sent to Google alone — never to Kyro.

Same Discord login as the site

No second Discord app to authorise. A content script on kyro.new.tg picks up the session the website already created.

Fine-tune the details

Category, OS, After Effects versions, reference link and description are all editable. Anything you change by hand is never overwritten by the next AI pass.

Duplicate check

While you type, EasyKyro compares your title with your own open requests and offers Upvote instead, so you do not file the same thing twice.

Right-click, or Alt+Shift+K

Send this page to EasyKyro, Request this link in EasyKyro and Request “…” in EasyKyro on a selection all open the popup pre-filled. The shortcut works on any tab.

Drafts survive

Your title and the generated details are kept per page, so closing the popup does not lose the request. It tells you when you are offline instead of failing silently.

Good to know

  • It is not in the Chrome Web Store. EasyKyro installs unpacked, which is why Chrome shows a small “Developer mode extensions” reminder. That badge is expected.
  • Updates are manual. Download the new .zip, extract over the old folder, then press the reload arrow on the EasyKyro card in chrome://extensions.
  • Requests need a verified Kyro Discord membership, exactly like the website form. Signing into Discord is not enough on its own.
  • The AI key is optional. Without it you can still send a request — you just write the description yourself instead of having it filled in.

Troubleshooting: if Chrome refuses the folder, confirm you extracted the zip and selected the folder that contains manifest.json. If the popup says it cannot reach Kyro, check you are online and already signed in on kyro.new.tg.
